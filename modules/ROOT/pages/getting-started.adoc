= Getting Started

Learn about UC Builder prerequisites, installations, and upgrades. 

== Prerequisites

To create connectors with UC Builder, meet these prerequisites.

=== OS Platforms

Your OS must be one of these:

* macOS (Intel or Apple Silicon) versions with Apple security update support. This is typically the latest release and the two previous versions. 
* Windows 10 or 11 (64-bit)
+
NOTE: Windows 10 is deprecated on https://support.microsoft.com/en-us/windows/windows-10-support-ends-on-october-14-2025-2ca8b313-1946-43d3-b55c-2b95b107f281[October 14, 2025].

=== Hardware

* Required hardware: 
** 10 GB of free storage space
** 8 GB of RAM
* Recommended hardware:
** 20 GB of free storage space
** 16 GB of RAM

=== Software

* Required software:
** https://code.visualstudio.com/download[VS Code] 1.99.3 and later, or https://docs.cursor.com/en/get-started/installation[Cursor] 1.5.9 and later
+
Cursor offers several advantages, specifically using AI for xref:base-connectivity.adoc#generate-base-connectivity-with-ai-assistance[base connectivity], xref:pagination.adoc#define-pagination-with-ai-assistance[pagination], and xref:testing-a-connector.adoc#run-tests-with-ai-assistance[tests].
** UC Builder extension 
** Dependent extensions
+
You must have these dependent extensions if you use your connector in Anypoint Code Builder or Anypoint Studio.
+
NOTE: If you use VS Code, the latest versions of these extensions are automatically installed when you install the UC Builder extension, so manual installation isn't required. If you use Cursor, install these extensions first, then install the UC Builder extension. For more information, see <<install-uc-builder>>.
+

** Anypoint Studio or Anypoint Code Builder
* Recommended software:
*** https://marketplace.visualstudio.com/items?itemName=salesforce.mule-dx-extension-pack[Anypoint Extension Pack]

== Install UC Builder

Install UC Builder in VS Code or Cursor.

=== Install UC Builder in VS Code

. In VS Code, select the Extensions icon in the Activity Bar.
. Search for `Universal Connectivity Builder` in the marketplace.
. Click *Install* on the extension.

=== Install UC Builder in Cursor

. Go to *View* > *Command Palette*.
. Enter `Preferences: Open User Settings`.
. Go to *Extensions > Gallery: Service Url*.
. Enter `\https://marketplace.visualstudio.com/_apis/public/gallery`.
. Restart Cursor. 
. Go to *View* > *Extensions*.
. Install the dependent extensions by searching for these extensions in the marketplace and clicking *Install*.
+
* https://marketplace.visualstudio.com/items?itemName=salesforce.mule-dx-vscode[Anypoint Code Builder - Platform Extension] 
* https://marketplace.visualstudio.com/items?itemName=salesforce.mule-dx-data-weave-client[Anypoint Code Builder - DataWeave Extension]
* https://marketplace.visualstudio.com/items?itemName=salesforce.mule-dx-dependencies[Anypoint Code Builder - Dependencies Extension]
* (Optional) https://marketplace.visualstudio.com/items?itemName=salesforce.mule-dx-extension-pack[Anypoint Extension Pack]
. Search for `Universal Connectivity Builder` in the marketplace.
. Click *Install* on the extension.

== Upgrade UC Builder

To ensure you're using the latest version of UC Builder, select the UC Builder extension in VS Code or Cursor and then select the *Auto Update* checkbox.
