= Getting Started

Learn about UC Builder prerequisites, installations, and upgrades. 

== Prerequisites

To create connectors with UC Builder, meet these prerequisites.

=== OS Platforms

Your OS must be one of these:

* macOS (Intel or Apple Silicon) versions with Apple security update support. This is typically the latest release and the two previous versions. 
* Windows 10 or 11 (64-bit)
+
NOTE: Windows 10 is deprecated on https://support.microsoft.com/en-us/windows/windows-10-support-ends-on-october-14-2025-2ca8b313-1946-43d3-b55c-2b95b107f281[October 14, 2025].

=== Hardware

* Required hardware: 
** 10 GB of free storage space
** 8 GB of RAM
* Recommended hardware:
** 20 GB of free storage space
** 16 GB of RAM

=== Software

* Required software:
** https://code.visualstudio.com/download[VS Code] 1.99.3 and later, or https://docs.cursor.com/en/get-started/installation[Cursor] 1.5.9 and later

Cursor offers several advantages, specifically using AI to generate base connectivity and pagination.

== Install UC Builder

Install UC Builder in VS Code or Cursor.

=== Install UC Builder in VS Code

. Install https://code.visualstudio.com/download[VS Code].
. Download the UC Builder extension (`.vsix` file).
. In VS Code, select the Extensions icon in the Activity Bar.
. Click the *More actions (...)* menu and then select *Install from VSIX*.
. Select the downloaded UC Builder extension (`.vsix` file).
. Click *Install*.
. A notification might appear to reload VS Code to start using the UC Builder extension. If it appears, click *Reload Now*.

=== Install UC Builder in Cursor

. Install https://docs.cursor.com/en/get-started/installation[Cursor].
. Install the dependent extensions:
+
* https://marketplace.visualstudio.com/items?itemName=salesforce.mule-dx-vscode[Anypoint Code Builder - Platform Extension] 
* https://marketplace.visualstudio.com/items?itemName=salesforce.mule-dx-data-weave-client[Anypoint Code Builder - DataWeave Extension]
* https://marketplace.visualstudio.com/items?itemName=salesforce.mule-dx-dependencies[Anypoint Code Builder - Dependencies Extension]
* (Optional) https://marketplace.visualstudio.com/items?itemName=salesforce.mule-dx-extension-pack[Anypoint Extension Pack]
. Download the UC Builder extension (`.vsix` file).
. In Cursor, select *View* and then select *Extensions*.
. Drag the downloaded UC Builder extension (`.vsix` file) onto the extensions list.

== Upgrade UC Builder

To upgrade to the latest version of UC Builder, you can either:

* Select the UC Builder extension in VS Code or Cursor and then select the *Auto Update* checkbox.
* Select the UC Builder extension in VS Code or Cursor and then click *Check for updates*.
